# واجهة Angular — نسخة Full Stack

هذه الواجهة مضبوطة افتراضيًا على `adapterMode: 'api'` وتتصل بخدمات ASP.NET Core عبر `/api`.

## التشغيل

1. شغّل SQL Server ونفّذ `backend/database/001_create_passengers.sql`.
2. شغّل API من مجلد `backend` على المنفذ 5009.
3. في Terminal أخرى نفّذ:

```powershell
npm ci
npm start
```

4. افتح `http://localhost:4200`.

إعداد `proxy.conf.json` يمرّر طلبات `/api` إلى `http://localhost:5009`. لا تستخدم وضع mock في الواجهة إذا كنت تريد اختبار الربط الحقيقي؛ تغيير الوضع موجود في `src/app/core/config/app-config.ts`.

المصادقة التجريبية متاحة في إعدادات Development فقط. بيانات المسافرين وزيارات المركبات محفوظة في SQL Server، بينما سياق المعبر وفهرس المعابر/البوابات وسجل التدقيق ما زالت تستخدم ذاكرة الخادم في هذه المرحلة.


## سجل المركبات

بعد تسجيل الدخول واختيار موقع العمل، افتح **سجل المركبات** من لوحة التحكم أو انتقل إلى `/vehicle-visits`. تعرض الصفحة السجلات التي يعيدها ASP.NET Core لموقع العمل الحالي، مع بحث برقم اللوحة أو رقم السجل وتصفية حسب حالة العبور. يلزم تشغيل API وقاعدة البيانات حتى تُحمّل السجلات.
