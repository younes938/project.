How Gate Companion works

The Gate Companion service runs on the computer at the gate, communicates with local equipment, and securely sends readings and device status to the E-Ticket backend. The current adapter is simulated until physical equipment and vendor protocols are connected.

Gate Equipment→Gate Companion→.NET API→SQL Server + E-Ticket UI
