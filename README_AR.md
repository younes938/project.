# E-Ticket Border Control — Full Stack

مشروع تخرج لإدارة المعابر الحدودية. الواجهة الأمامية Angular، والخلفية ASP.NET Core / C#، وقاعدة البيانات SQL Server. لا يستخدم React أو Node.js كخادم خلفي؛ Node.js مطلوب فقط لتشغيل أدوات بناء Angular.

## الوظائف المفعّلة في هذا الإصدار
- تسجيل الدخول التجريبي بجلسة Cookie وحماية CSRF في Development فقط.
- إدارة المسافرين مع CRUD والبحث/التصفية وتخزين SQL Server.
- تسجيل المركبات وسجل زياراتها عبر ASP.NET Core وتخزين SQL Server.
- إدارة الشحنات: إنشاء/عرض/بحث/تعديل/حذف وحالة جمركية.
- التفتيش الأمني: إنشاء/عرض/بحث/تعديل/حذف، ملاحظات، حالة، وإنذار أمني.
- لوحة تحكم تسحب أعداد المسافرين والمركبات والشحنات والتنبيهات من API.
- تقارير ملخصة مع تصدير CSV، وإمكانية طباعة/حفظ التقرير كـ PDF من نافذة الطباعة.
- سجل تدقيق محفوظ في SQL Server لعمليات تسجيل الدخول وتغييرات بيانات الشحنات والتفتيش.

## تشغيل المشروع
راجع `START_HERE_AR.md`؛ يحتوي خطوات إعداد SQL Server وتشغيل الخادم والواجهة بالتفصيل. نفّذ ملفي قاعدة البيانات بالترتيب: `001_create_passengers.sql` ثم `002_create_operations.sql`.

## حالة الجاهزية وحدود النسخة
هذه نسخة تطوير/عرض وظيفية وليست نظامًا إنتاجيًا معتمدًا. تسجيل الدخول الحالي تجريبي بمستخدم واحد محدود الصلاحيات؛ لم تُبنَ بعد شاشة إدارة حسابات الموظفين وكلمات المرور الحقيقية وتوزيع الأدوار على جميع الوحدات. كما أن إعدادات المعابر والبوابات ما زالت تجريبية داخل ذاكرة الخادم، والربط الحكومي وقراءة اللوحات ANPR والكاميرات والجمارك الفعلية غير مفعّل. يلزم تشغيل البناء والاختبارات على جهاز تطوير مع .NET SDK وnpm واتصال SQL Server، ثم إكمال مراجعة أمنية واختبارات قبول قبل تسليم نهائي رسمي أو استخدام بيانات حقيقية.
